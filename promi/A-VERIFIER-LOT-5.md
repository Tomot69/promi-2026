# TOM PEUT UTILISER L'APP 5 MINUTES — le lot 5 (le Cercle et ses membres), à vérifier sur l'iPhone, dans l'app « Promi »

**Installée le … — commit `…`** (à remplir à l'installation, lu sur le téléphone : `sh outils/version-iphone.sh`).
Pour chaque point : **tenu**, **non tenu** ou **non vu**. Ton téléphone n'a pas encore de Cercle : on en crée un d'abord.

1. **Créer un Cercle** — le + → « Un Cercle », un nom, deux personnes, tracer : un seul Cercle, une seule dalle sur la Toile, une ligne au Fil.
2. **Sa fiche** — toucher sa dalle : la fiche monte ; la bande et sa vague, « Toi » et le disque du Cercle avec le + orange à côté, « Avec … », son
   nom, « ENCORE AUCUNE PAROLE », « Planter dans le Cercle » collé en bas, la barre Peaufiner lilas.
3. **« Planter dans le Cercle »** → le petit menu (Chiche, Promi) ; Promi : la page + s'ouvre avec tes deux personnes déjà choisies ; plante.
   Rouvre le Cercle : la parole est dans son fil ; fais défiler le fil (dix allers-retours) — la vague se couche sous le plateau, rien ne saute,
   « Avec … » reste. Toucher la ligne ouvre sa parole.
4. **Peaufiner du Cercle** (sa barre) — écris une DESCRIPTION, ferme l'app, rouvre : elle est gardée. Le + orange ouvre MEMBRES déplié : retire
   quelqu'un, « Avec … » suit. DISSOUDRE (tout en bas) : la feuille, puis « Annuler » le rend ; dissous pour de bon, la parole reste, hors du Cercle.
5. **« Un mot… »** sur la fiche du Cercle : écris, envoie — le mot se pose sous « LES MOTS », au bout du fil ; une ligne au Fil.

Pas encore : les murs de Ma Parole ! de Peaufiner (leur phrase : lot 8) ; LE TRAIT d'un Cercle se choisit et se garde (ce
qu'il change ailleurs n'est pas porté) ; le dessin d'un Cercle (son bouton photo) ; les mots neufs d'un Cercle venus d'un autre (avec la synchro).
