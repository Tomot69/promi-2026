# Le titre modifiable (lot 3a-4) — à vérifier sur l'iPhone, dans l'app « Promi »

Pour chaque point : **tenu**, **non tenu** ou **non vu** (R4). Ouvrir une parole en touchant sa dalle sur la Toile.

1. **Toucher le titre** (un titre court) : il devient modifiable sur place, le curseur là où le doigt a touché, le clavier s'ouvre ; **aucun encart**
   autour du titre (ni contour, ni fond) — seul le curseur clignote.
2. **Taper, puis Retour** : le titre neuf sur la fiche ; dans la Toile, le titre écrit sur la dalle change, **la dalle garde sa forme**.
3. **Toucher ailleurs pendant la modification** : le titre est validé.
4. **Tout effacer, puis Retour** : l'ancien titre revient, en se traçant.
5. **Un titre très long** (coupé par « … ») : le premier toucher le déplie en entier (ce qui suit glisse, ≈ 0,4 s) ; le second le modifie.
6. **Clavier ouvert, un titre qui descend sous le clavier** : la fiche glisse pour garder le curseur au-dessus du clavier.
