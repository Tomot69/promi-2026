Le tracé des lettres

Aucun texte n’apparaît d’un bloc. Chaque lettre se trace le long de sa ligne médiane ; le front est une coupe nette, perpendiculaire au chemin. Les réglages sont en bas de l’écran.

« Réduire les animations » est actif sur cet appareil : dans l’app, le texte serait posé d’un coup. Cette page trace quand même.

Un glyphe, de près

Toucher une loupe trace le glyphe, cinq fois plus lentement que le texte. Une lettre commence du côté où la précédente a fini : chaque glyphe a donc deux tracés, quand sa forme le permet.

Rond : le départ. Carré : l’arrivée. Les chiffres : l’ordre des traits, chacun avec sa pointe. Tirets : un repassage sur une partie déjà tracée (invisible, un instant). Pointillés : un saut d’un morceau à l’autre (invisible).
